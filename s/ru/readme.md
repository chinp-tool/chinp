# chinp

Анализатор входов для Linux серверов

## Установка

Русская версия:
curl -sSL https://raw.githubusercontent.com/chinp-tool/chinp/main/s/ru/s/install/version/1/install.sh | sudo bash

## Использование

```bash
chinp <опции>
```

## Описание

chinp анализирует попытки входа на сервере, извлекает айпи адреса из логов и показывает гео инфу о каждом адресе.

## Возможности

- извлечение уникальных IP из auth.log
- отображение страны и города для каждого IP
- фильтрация неудачных попыток входа
- сортировка по частоте
- фильтрация по порту и протоколу
- поиск аномальной активности
